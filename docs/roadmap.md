# Роадмап

Стратегический план: цель, что делаем и в каком порядке, что не делаем. Тактика каждого изменения —
в его `tasks.md` в `openspec/changes/`. Формат — решение [24](pre-init/24-planning-tracking.md):
агент предлагает, человек утверждает. Приоритеты — «обязательно / желательно / если успеем / не
делаем».

## Цель

REST API для управления задачами и их статусами по тестовому заданию ([docs/task/](task/README.md)):
поднимается одной командой, ведёт себя предсказуемо в неидеальных сценариях, код и архитектура
объяснимы без ИИ. Сдача — до 2026-10-09 (`CON-PLAN-deadline`).

## Главный приоритет

Аккуратно сделанная база важнее дополнительных функций. Если времени не хватает — стабильно работающий
CRUD и чистые миграции, а в README честно написано, что не успели (`docs/task/assignment.txt:13`).

## Вне рамок

Не делаем (`docs/task/assignment.txt:141`):

- пагинацию;
- сложную авторизацию и админку;
- деплой на внешний сервер (готовность к нему — да: сценарий качества `QAS-DEPLOY-prod-image`, см.
  [архитектуру](architecture/README.md#1-цели-качества)).

([02](pre-init/02-sdd-framework.md)). Порядок и нарезку продуктовых изменений утвердил человек
(2026-10-07); имена станут именами папок в `openspec/changes/`.

Процессные улучшения «если успеем» из [34](pre-init/34-core-vs-roadmap.md) §3 (Infection в CI, Psalm
taint, скрипты формы изменений и ADR, правила PHPStan, проверка `Assisted-by`, markdownlint и lychee,
настройка `/security-review`) — все семь — перенесены до продукта, в изменение 1b `finish-init`; линия
отсечения — Infection и Psalm: если они не зелёные к концу остальных задач, возвращаются сюда (решение
владельца, 2026-10-07).

Кандидаты процесса без срока (решения владельца, 2026-10-07):

- задержка свежих релизов зависимостей Composer — встроенной настройки нет, кандидаты: плагины
  `zingstudios/composer-delay`, `innobrain/soak-time`, Heimdall; каждый — новая зависимость
  ([35](pre-init/35-init-checklist.md), проверки при настройке);
- песочница Claude Code — выключена, вернуть через узкий профиль AppArmor (`DEBT-001-sandbox-disabled`).

### Чек-лист сдачи

- [ ] README: разделы задания заполнены (`CON-DELIV-readme-sections`), «Быстрый старт» проверен на
  чистом клоне.
- [ ] Репетиция без ИИ: человек сам вносит небольшое изменение в отдельной ветке
  ([31](pre-init/31-task-requirements.md) §2).
- [ ] В копии документа задания заполнены «Ваше решение» (ссылка на репозиторий, хеш коммита
  `git rev-parse HEAD`) и «Ваши контакты»; открыт доступ на чтение; ссылка отправлена рекрутеру
  (`docs/task/assignment.txt:8-9, 144-150`).
- [ ] После отправки — в `main` не пушить; правки только в отдельной ветке (`CON-DELIV-frozen-main`).
