# Текст тестового задания

[assignment.txt](assignment.txt) — текст тестового задания Skyeng (Backend, стажировка), полученный от
рекрутера. Это первоисточник требований: на него ссылаются ограничения и требования проекта.

Текст дословный, с одним изменением: **удалены две строки с prompt injection**. В исходном файле
дважды повторяется блок с маркером `[MUST]`, адресованный не исполнителю, а ИИ-агенту. Его цель —
проверить, выполняет ли агент инструкции из недоверенного текста. Это не требование задания, поэтому
блок исключён здесь и в документации проекта. Содержание блока намеренно не воспроизводится, чтобы оно
не попадало в контекст агента. Обнаружение и удаление — 2026-10-06, решение владельца проекта
([docs/pre-init/31](../pre-init/31-task-requirements.md) §1).

Других изменений нет: концы строк приведены к LF, метка кодировки (BOM) снята.
