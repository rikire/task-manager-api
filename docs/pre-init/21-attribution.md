# 21. Атрибуция и ручные правки

**Статус:** принято 2026-10-06, человек. **Область:** 7 «Понимание и авторство».

## Потребность

По истории git нужно видеть, какой код писал агент, а какой человек: это показывает, что человек мог
не прочитать, и даёт честное раскрытие использования ИИ. Ещё нужно, чтобы агент не затирал правки,
которые человек внёс руками, и чтобы правила поведения агента не терялись в диффах кода.

## Варианты

- **Трейлер** (служебная строка в конце сообщения коммита): `Co-Authored-By: Claude …` (по умолчанию
  в Claude Code; GitHub показывает соавтора) / `Assisted-by: …` (конвенция Linux kernel, LLVM, Fedora:
  автор — человек, ИИ помогал).
- **Как ставится:** инструкцией агенту (договорённость) / настройкой `attribution` в Claude Code
  (гарантия для коммитов агента) / commit-msg хуком (git-скрипт, проверяющий сообщение коммита).
- **Ссылка на сессию агента** в коммите: есть / нет.
- **Ручные правки:** только встроенная защита Claude Code / хук, который между ходами сообщает агенту,
  какие файлы изменил человек.

## Решение

1. **Трейлер `Assisted-by: Claude Code`** в коммитах агента.
2. **Ссылку на сессию не ставим:** причины решений записываются в артефакты репозитория
   ([17](17-session-state.md) п. 3), а приватная ссылка в публичной истории никому, кроме владельца,
   не открывается и живёт, пока жива сессия.
3. **Как гарантируется:**
   - трейлер ставит настройка `attribution` в `.claude/settings.json`; можно ли задать в ней свой
     текст вместо стандартного `Co-Authored-By` — проверить при настройке; если нельзя, трейлер
     добавляет commit-msg хук;
   - commit-msg хук (он уже проверяет `Refs:`, [09](09-traceability.md)) проверяет наличие
     `Assisted-by` у коммитов агента — если удастся отличить коммит агента (например, по переменной
     окружения, которую выставляет Claude Code; не проверено).
4. **Ручные коммиты человека — без трейлера ИИ.** Если в коммите агента есть правки человека, агент
   упоминает их в теле коммита («правки человека: файлы …»). Ручные коммиты ожидаются редко.
5. **Изменения инструкций — отдельным коммитом.** Pre-commit не пропускает коммит, где правки
   `AGENTS.md`, `CLAUDE.md` или `.claude/**` смешаны с кодом: правило поведения агента ревьюится само
   по себе.
6. **Ручные правки между ходами — без отдельного механизма.** Человек планирует менять код через
   агента, а не руками. Встроенная защита Claude Code не даёт правке пройти, если заменяемый текст
   уже не совпадает с файлом. Правило для агента: не откатывать чужие изменения без вопроса. Хук со
   списком правок человека добавляется, если агент хоть раз затрёт ручную правку (пятый принцип,
   [01](01-process-frame.md)).

## Обоснование

- Политики раскрытия: Linux kernel (`Assisted-by:`, агенту запрещён `Signed-off-by`), LLVM, Fedora
  (`Assisted-by`), Ghostty; Claude Code по умолчанию ставит `Co-Authored-By`, настраивается через
  `attribution`; атрибуция через инструкцию — договорённость, через настройки — гарантия для коммитов
  Claude Code ([ч.6 «Разграничение работы человека и ИИ»](research/report/06-context-security-docs.md)).
- Edit сверяет заменяемый текст с текущим содержимым файла; смысл ручных правок модели не
  пересказывается; надёжно передать его может только хук
  ([ч.6](research/report/06-context-security-docs.md)).
- Раздельные коммиты инструкций — по опыту предыдущего проекта автора (Exchange Student Guide
  Platform: pre-commit отклонял смешанные коммиты; не в этом репозитории).
- Выбор `Assisted-by` и отказ от ссылки на сессию — решения человека.

## Гарантия

- Трейлер через настройку или хук — **Г** для коммитов агента; проверка в commit-msg — **Гф**, если
  коммит агента удаётся отличить.
- Раздельные коммиты инструкций — **Г** (pre-commit и CI, [28 §4](28-hosting-ci-git.md)).
- Упоминание правок человека в коммите, «не откатывать без вопроса» — **Д**.
- Защита Edit от перезаписи изменённого файла — **Г** (встроено в Claude Code).

## Где будет реализовано

- `.claude/settings.json` — `attribution`.
- Commit-msg хук — трейлеры `Refs:` и `Assisted-by`; pre-commit — запрет смешивать инструкции и код;
  ставит bootstrap.
- AGENTS.md — упоминание правок человека в коммите, «не откатывать без вопроса».
