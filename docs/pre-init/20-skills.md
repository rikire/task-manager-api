# 20. Поиск, оценка и создание скиллов

**Статус:** принято 2026-10-06, человек. **Области:** 8 «Обучение процесса», 4 «Контекст и
инструкции».

## Потребность

Подходящий скилл заметно меняет результат: например, официальный скилл `doc-coauthoring` дал
работающую проверку текстов читателем ([19](19-agent-writing.md)). Сам агент скиллы не ищет и не
оценивает. Нужно, чтобы он находил скиллы под задачу (в проекте, в каталогах, в интернете),
проверял, насколько они подходят и безопасны, ставил их только с одобрения человека, а при
необходимости писал и дорабатывал свои.

Скилл — файл `SKILL.md` с инструкцией-процедурой, которую агент загружает при вызове; формат открытый
(Agent Skills). Плагин — пакет из скиллов, агентов, хуков и MCP-серверов; каталог плагинов —
маркетплейс.

## Варианты

- **Поиск:** по запросу человека / по триггеру в процессе.
- **Источники:** свои скиллы; официальный маркетплейс Anthropic `claude-plugins-official` и
  репозиторий `anthropics/skills`; community-маркетплейс; GitHub; интернет.
- **Оценка:** карточка с описанием и рисками / прогон на своих задачах со скиллом и без
  (`skill-creator` Comparator, `claude plugin eval`) / испытательный срок в реальной работе.
- **Установка:** плагин из маркетплейса (области «пользователь», «проект», «локально») / копия скилла
  в репозитории.
- **Создание своих:** вручную / через официальный `skill-creator` (создание, evals, сравнение,
  улучшение description для срабатывания).

## Решение

### 1. Когда агент ищет скилл

- Перед новым типом задачи — на этапе proposal изменения ([07](07-requirements-intent.md)).
- Когда одна и та же ручная процедура повторилась дважды — предлагает сделать из неё скилл.

Порядок поиска: карта AGENTS.md ([03](03-agent-instructions.md)) → установленные скиллы и плагины →
официальные каталоги (`claude-plugins-official`, `anthropics/skills`) → community-маркетплейс,
GitHub, поиск в интернете ([15](15-agent-security.md)).

### 2. Уровни доверия

| Источник | Что можно |
|---|---|
| свои скиллы в проекте | использовать |
| официальные Anthropic | ставить после одобрения человека |
| community, GitHub, интернет | только кандидат: агент читает весь `SKILL.md` и скрипты, описывает риски; решает человек |

### 3. Карточка кандидата

Агент приносит её до установки:
- источник, сопровождающий, дата последнего обновления, лицензия;
- что ставит: скиллы, хуки, MCP, скрипты, сеть, разрешения инструментов (`allowed-tools`);
- стоимость в контексте (`/plugin` показывает её для официального маркетплейса;
  `claude plugin details` — для установленного);
- пересечения и противоречия с нашими правилами (например, свой TDD-процесс против
  [05](05-tdd.md));
- рекомендация: поставить / скопировать и доработать / написать свой / не брать.

### 4. Проверка, что скилл помогает

- **По умолчанию — испытательный срок:** скилл используется в обычной работе несколько изменений;
  если пользы нет, удаляется.
- **Прогон на своих задачах** (3–5 кейсов со скиллом и без, по 3 раза; принимается, если разница
  больше шума) — только если:
  - скилл заменяет часть нашего процесса (тесты, ревью, приёмку);
  - выбираем между двумя похожими скиллами;
  - скилл ведёт себя подозрительно — не срабатывает, когда должен, или срабатывает не там.

### 5. Установка

Решение человека — как с пакетами ([13](13-authority.md), [15](15-agent-security.md)).
- **Скиллы без скриптов и хуков** копируются в `.claude/skills/<имя>/` с пометкой источника и
  версии: воспроизводимо, проходит ревью, можно дорабатывать, не меняется само.
- **Плагины с хуками или MCP** ставятся в области «проект» с закреплённой версией маркетплейса
  (`#ref`); устанавливает их bootstrap ([29](29-environment.md)),
  чтобы после клонирования ничего не делать руками.
- Автообновление сторонних маркетплейсов выключено.

### 6. Заменить или дополнить

- В скопированном скилле наши правки помечаются «изменено под проект» с причиной.
- Если исходный скилл обновился, агент показывает дифф; переносить ли — решает человек.

### 7. Свои скиллы

- Пишутся и дорабатываются через официальный `skill-creator`.
- У каждого скилла: точный `description` и `when_to_use` (по ним модель решает, когда вызвать
  скилл); `disable-model-invocation` для скиллов с побочными эффектами; минимальные `allowed-tools`;
  кейсы evals рядом со скиллом (для прогона из §4, когда он нужен).
- Правка `.claude/**` — под `ask`, отдельным коммитом ([21](21-attribution.md)).
- В pre-commit — проверка формата frontmatter скиллов; для плагинов — `claude plugin validate`
  (синтаксис и схема, не поведение).
- По лестнице из [01](01-process-frame.md) скилл — договорённость: если ошибку можно поймать тестом
  или хуком, сначала делаются они, скилл — дополнительно.

### 8. Гигиена

Периодически — список «Not used recently» в `/plugin` и стоимость в контексте; неиспользуемое
удаляется (четвёртый принцип: артефакт должен окупаться).

## Обоснование

- Расположение и вызов скиллов, поля frontmatter, открытый формат Agent Skills —
  [code.claude.com/docs/en/skills](https://code.claude.com/docs/en/skills); маркетплейсы, области
  установки, автообновление, «Not used recently», стоимость в контексте —
  [code.claude.com/docs/en/discover-plugins](https://code.claude.com/docs/en/discover-plugins);
  обе страницы прочитаны 2026-10-06.
- `skill-creator` (Eval, Benchmark, слепое сравнение, оптимизация description: срабатывание
  улучшилось на 5 из 6 публичных скиллов — вендор); `claude plugin eval` (с плагином / без / разница,
  3 прогона); форматы несовместимы; `claude plugin validate` проверяет синтаксис, не поведение
  ([ч.7 §6–7](research/report/07-guardrails-harness-process.md)).
- Скилл, который модель должна вызвать сама, срабатывает не всегда — отсюда карта в AGENTS.md
  ([03](03-agent-instructions.md), [ч.6](research/report/06-context-security-docs.md)).
- Плагины могут запускать хуки и MCP, скиллы — скрипты: это зависимость с риском prompt injection
  ([15](15-agent-security.md)).
- Испытательный срок вместо обязательного прогона — решение человека: прогон дорог, нужен в
  перечисленных случаях.

## Гарантия

- Поиск по триггеру, карточка кандидата, испытательный срок — **Д**.
- Установка — промпт **Г** (правка `.claude/**` и установка — под `ask`), решение **Ч**.
- Прогон со скиллом и без — измерение, не гарантия; вердикт по разнице — **Ч**.
- Формат frontmatter, `claude plugin validate` — **Гф**.
- Скопированные скиллы не меняются без коммита — **Г** (git).

## Где будет реализовано

- Шаг «есть ли скилл под задачу» — в скилле работы над изменением; строка в карте AGENTS.md.
- `.claude/skills/<имя>/` — свои и скопированные скиллы с пометкой источника.
- `.claude/settings.json` — плагины в области «проект», выключенное автообновление сторонних;
  установка — в bootstrap.
- Проверка frontmatter и `claude plugin validate` — в pre-commit.
